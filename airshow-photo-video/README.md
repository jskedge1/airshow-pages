# Your first airshow photos: cartoon motion design video

Same house style as `airshow-season-video/` (see `.claude/skills/cartoon-motion-design/SKILL.md`),
with a few format changes for the photography subject.

- `airshow-photos.mp4`: 16:9, 1920x1080, 60 fps, about 1 min 24 s
- `airshow-photos-tiktok.mp4`: 9:16, 1080x1920 (TikTok, Reels, Shorts)

## Steps
1. Use the camera you own
2. Get a long lens
3. Set up before the flying
4. Fast jets: 1/1000 second or faster
5. Propeller aircraft: about 1/320 second for prop blur
6. Static aircraft: aperture priority, f/7.1 to f/11
7. Pack for a photo day
8. Review and repeat

The copy follows the site's own guide, `new-to-aviation-photography.html`.

## What's new in this format
- **Shutter transition:** a camera shutter curtain sweeps down between steps, with a click,
  instead of the cloud wipe.
- **Viewfinder overlay:** focus brackets and a focus point frame each scene, and a settings
  readout shows the live camera settings, for example "S 1/1000 AUTO ISO", or the shutter speed
  stepping down as the propeller blurs.
- **Snap and print:** each step ends with a flash and a square photo print of the scene.
- **The prints come home:** the review step shows the prints in a gallery on a monitor, with
  stars on the best ones.
- **New aircraft:** a P-51 Mustang cut-out from the site
  (`camping-layout/img/091c503adc4bcb3c.webp`), drawn with a blurring propeller disc.
