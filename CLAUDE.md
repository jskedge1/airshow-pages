# House rules

- Logo: always use the new logo with the swishes, never the old red jet header (`brand/uk-airshow-guide-header.png`).
  Use `brand/UK-Airshow-Guide-logo-transparent.png` (navy lettering) on light backgrounds and
  `brand/ukag-header-logo.png` (white lettering) on dark ones.
- Posters (`posters/`, built by `posters-src/build.py`): no rounded corners anywhere, real photos and cut-outs
  rather than drawn aircraft, and every fact taken from a page on the site.
- README.md is the running record of how the site is built. Read the section for the page you are changing.
