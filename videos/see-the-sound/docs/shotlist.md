# See the Sound: shot list
105 s · 80 bpm · 140 beats · 16x9
Music: synthesised calm lofi bed (F major). No voice-over: every tip is on screen.
Idea: the airshow is drawn the way Charlie hears it. Each noise is a shape, and each tip visibly calms the picture.

Sensory rules: no flashes, no shake, a countdown before every loud moment, soft sounds only.
House rules: square corners on every box and label; aircraft are the real cut-outs used in the other UK Airshow Guide cartoons (shared/aircraft/).
