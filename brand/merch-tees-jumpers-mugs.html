05

Good to know

Before any of these go to a printer.

Mix and match

  • Every design fits every product. The combinations here are suggestions. Tell me which pairings you want and I will redraw them.
  • Colours can change. Each design works in a dark-ink and a light-ink version, so it can go on any cloth or glaze colour.
  • Runway 27 is this season's number. It can be reissued as runway 28 for 2028, which gives people a reason to buy again.

Before ordering

  • Designs B to G are drawn as vectors, so they scale to any print size. I can export each one as a print-ready file.
  • The logo still needs a vector version. The current PNG is fine for a chest print or a mug, but not for anything larger than about 14 cm.
  • The knitted jumper is made to order by a knitwear supplier, usually with a minimum run of about 50.
  • The jets are generic shapes I drew, not any real aircraft type or display team.
